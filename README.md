# 电磁场与电磁波学习笔记

这是一份长期维护的《电磁场与电磁波》课程学习仓库。笔记不只是罗列公式，而是按“**定义 → 直观理解 → 计算方法 → 做题方法 → 易错点**”组织，并把课堂上的真实疑问融入解释。

### 第二章：静电场

- [静电场学习笔记（源量与场量 → 电荷分布 → 库仑定律 → 电场积分 → 典型例题）](chapter-02-electrostatics/electrostatics-study-notes.md)

## 推荐学习顺序

1. 先读完整学习笔记，抓住老师划定的重点和本章总框架。
2. 再用概念笔记查定义，用题型库学习如何选择公式。
3. 独立完成练习题，不要同时打开答案。
4. 对照答案定位错误，并把错因写回自己的笔记。

## 第一章知识地图

```text
标量场 ──方向导数──> 梯度 ──再求散度──> 拉普拉斯
矢量场 ──穿过曲面──> 通量 ──局部化──> 散度 ──积分化──> 散度定理
矢量场 ──沿圈推动──> 环流 ──局部化──> 旋度 ──积分化──> 斯托克斯定理
```
