## 推荐学习顺序

1. 先读完整或基础学习笔记，抓住课程主线和老师划定的重点。
2. 再用概念笔记查定义、公式来源和适用条件，用题型库学习如何选择公式。
3. 有配套练习时先独立完成，不要同时打开答案。
4. 对照答案定位错误，并把错因写回自己的笔记。

## 第一章知识地图

```text
标量场 ──方向导数──> 梯度 ──再求散度──> 拉普拉斯
矢量场 ──穿过曲面──> 通量 ──局部化──> 散度 ──积分化──> 散度定理
矢量场 ──沿圈推动──> 环流 ──局部化──> 旋度 ──积分化──> 斯托克斯定理
```

## 第二章知识地图

```text
电荷 ──库仑定律/叠加──> 电场强度 ──散度/旋度──> 有源、无旋
介质极化 ──极化强度──> 电位移矢量 ──高斯定理──> 只追踪自由电荷
静电场基本方程 ──积分定理──> 微分形式 ↔ 积分形式
介质界面 ──边界条件──> 电位移矢量法向跳变、电场强度切向连续、场矢量折射
导体表面 ──静电平衡──> 切向场为零、法向通量对应自由面电荷、导体等位
无旋场 ──定义电位──> 泊松/拉普拉斯方程 ──边界条件──> 电位法
```
